# 如何从内容流平台学习网页设计

## 1. 先学信息流，不急着学视觉特效

小红书式体验最值得借鉴的是内容组织方式：用户一进入页面就能看到大量可浏览、可筛选、可收藏的内容单元。对于开源网页设计站，这意味着首页应该优先展示设计案例，而不是长篇项目介绍。

## 2. 每个卡片都要回答一个问题

一个好的设计卡片至少要回答：

- 这个设计适合什么场景？
- 它有什么视觉关键词？
- 它能拆成哪些组件？
- 它对应什么技术栈？
- 我能不能看到 Demo 或源码？

## 3. 把审美拆成工程维度

不要只说“这个页面高级”。更可复用的表达是：

- 首屏结构：标题、说明、主按钮、视觉图如何分布。
- 层级：最重要的信息是否一眼可见。
- 色彩：主色、辅助色、背景色如何服务主题。
- 组件：哪些模块可以被抽象为可复用组件。
- 动效：是否真的帮助用户理解，而不是只为了炫。

## 4. 周末可发布 Demo 建议

本周末发布的最小成果可以是：

- 一个静态首页。
- 6 个设计案例。
- 一篇设计拆解方法论笔记。
- 一张项目截图。
- 一个清晰的 README。

这个版本不需要后端。先把“内容结构”和“项目气质”跑通，再考虑投稿、登录、收藏和真实案例库。
